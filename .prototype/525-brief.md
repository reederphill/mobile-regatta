## 6. Open design choices, with defaults (decide, note in findings, do not stall)
1. Pack definition: >=3 boats within 20 m of the boat at her pick tick (not transitive chains), deduped by seat set. Default as written.
2. "Passed outside while entitled": as defined in (b)(ii); if no roundings qualify, report the denominator and say entitlement is rare, which itself favours hand fix H2 over a planner.
3. "With and without current": saltings-reach@1 rows vs the other three venues; build a one-venue `--matrix` file only if the split is too noisy.
4. Roll-out helm: autohelm hold toward the point (as `EscapeSimulation`), not her hand-steering model; Q3 measures what that costs. Only the first aim is sailed via `navigate`/`downwindAim`.
5. "Outside" candidate = main's behaviour, so the planner can only differ from main when "inside" or another mark scores more than `gateRepickMetres` better.
6. Dirty-air weight `wDirty`: start 3 m per second, sweep 0/3/6 once.
7. Time grid: start at 0.2 s steps (6x cheaper), refine to 0.1 s only if Q3 shows it matters.
8. Replan every decision (3 ticks); test every 3rd only for Q4.
9. Tier lever: horizon and candidates from skill (ramp .35->1), no noise; add noise only if the tier gap does not open.
10. If P+H beats P and H alone, the finding is "both"; report each part's marginal gain.
